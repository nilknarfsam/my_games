| [`jogar_forca.bat`](jogar_forca.bat) | **Jogo da Forca** | Python + Tkinter |
| [`jogar_carro.bat`](jogar_carro.bat) | **Jogo de Carro (3 Faixas)** | Python + Tkinter |
| [`jogar_nave.bat`](jogar_nave.bat) | **Jogo de Nave** | Python + Tkinter |
| [`jogar_cobrinha.bat`](jogar_cobrinha.bat) | **Jogo da Cobrinha** | Python + Tkinter |
| [`jogar_tetris_3d.bat`](jogar_tetris_3d.bat) | **Tetris 3D** | Three.js + Vite (Navegador) |
| [`jogar_xadrez_3d.bat`](jogar_xadrez_3d.bat) | **Xadrez 3D** | Three.js + Vite (Navegador) |
