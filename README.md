# Projetos em Python e C++

Repositório organizado por projeto e linguagem:

- [`python/`](python/README.md): Cronômetro em Python (**Tkinter**).
- [`cpp/`](cpp/README.md): Cronômetro em C++17 (**Win32 API**).
- [`jogo_da_forca/`](jogo_da_forca/README.md): Jogo da Forca com 100 palavras aleatórias e cronômetro de 20s por letra em Python (**Tkinter**).
- [`jogo_de_carro/`](jogo_de_carro/README.md): Jogo de Carro em pista de 3 faixas com 10 níveis de velocidade e carros aleatórios dinâmicos em Python (**Tkinter**).
- [`jogo_de_nave/`](jogo_de_nave/README.md): Jogo de Nave com movimento em 4 direções, 3 corações, 3 níveis de tiro, bombas/armas especiais de 20s e naves malucas em Python (**Tkinter**).
- [`jogo_da_cobrinha/`](jogo_da_cobrinha/README.md): Jogo da Cobrinha com crescimento, objetos de obstáculo e outras cobras no campo em Python (**Tkinter**).
- [`jogo_cs_2d/`](jogo_cs_2d/README.md): Jogo CS 2D tático com visão pelo mouse, movimentação WASD, tiro/recarga e 2 oponentes em Python (**Tkinter**).
- [`jogo_cs_2d_godot/`](jogo_cs_2d_godot/README.md): Versão multiplayer em rede (ENet / UDP) do CS 2D em **Godot 4** com sombras 2D reais e servidor autoritativo.
